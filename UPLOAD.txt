طريقة رفع الموقع مع لوحة التحكم
================
1. فك ضغط الحزمة.
2. اتبع أولًا دليل setup/README-AR.md لإنشاء قاعدة بيانات Supabase وحساب المدير وإضافة بيانات الربط العامة.
3. ارفع ملفات HTML الخمسة، ومنها admin.html، ومجلد assets إلى جذر مشروع GitHub Pages.
3. حافظ على أسماء الملفات ومجلد assets كما هي.
4. افتح الموقع واختبر صفحة الخدمات الزكوية والضريبية.

صفحة الخدمات الجديدة: tax-services.html
التواصل: 0535802823
طلبات الخدمة تنتقل إلى واتساب برسالة جاهزة؛ يراجعها العميل ويرسلها.
النموذج لا يرفع ملفات أو إقرارات إلى الهيئة ولا يُجري تقديمًا حكوميًا تلقائيًا.
تُحدّد التكلفة بعد مراجعة احتياج الجمعية.
الدخول إلى لوحة التحكم: admin.html، باسم admin وكلمة المرور التي تختارها في Supabase.
لا توجد كلمة مرور افتراضية، ولا تُحفظ الطلبات والإحصاءات قبل ربط قاعدة البيانات.
